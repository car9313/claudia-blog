# Sistema de Imágenes Mejorado

Nuestro blog ahora soporta tanto imágenes locales como externas con manejo profesional de errores.

## Imágenes Locales

Las imágenes locales funcionan como siempre:

![Ejemplo local](/placeholder.svg?height=400&width=800&query=blog+de+programacion)

## Imágenes Externas

Ahora puedes usar imágenes de cualquier URL externa:

![Ejemplo de Cloudinary](https://res.cloudinary.com/demo/image/upload/sample.jpg)

## Manejo de Errores

Si una imagen no se puede cargar, se muestra un placeholder elegante:

![Esta imagen no existe](https://ejemplo.com/imagen-que-no-existe.jpg)

## Características

- Lazy loading automático
- Skeleton loader mientras carga
- Fallback elegante si falla la carga
- Soporte para modo claro y oscuro
- Alt text como caption
- Optimización automática
